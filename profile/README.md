# 50by35 GitHub

This GitHub organization hosts the code and documentation developed as part of a joint World Bank and UNHCR initiative to measure progress toward the self-reliance component of the [**50by35 vision**](https://www.unhcr.org/50-by-35) — a global commitment by the UN High Commissioner for Refugees to reduce the number of aid-dependent refugees in protracted displacement by 50 percent by 2035. Self-reliance is defined operationally as having consumption, net of humanitarian assistance, above the national poverty line. Measuring this concept rigorously requires stripping the value of humantitarian asssitence from household consumption aggregates, and imputing self-reliance for countries without data. This GitHub organization currently hosts the following repositories.

- [**harmonization:**](https://github.com/50by35/harmonization) code to harmonize refugee consumption surveys across countries
- [**pipeline:**](https://github.com/50by35/pipeline) technical documentation and code for the end-to-end microdata pipeline
- [**global-imputation:**](https://github.com/50by35/global-imputation) methods and code for nowcasting and gap-filling estimates where microdata are unavailable
- [**monitoring-handbook:**](https://github.com/50by35/monitoring-handbook) living handbook for measuring the self-reliance component of the 50by35 target through 2035
